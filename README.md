# Banco-de-dados-de-parâmetros-de-qualidade-de-gerador-diesel-elétrico-UFRN.
O presente repositório contém o banco de dados de 29 parâmetros de qualidade de um gerador diesel-elétrico da UFRN como parte das contribuições do artigo "Desenvolvimento de hardware e dashboard supervisório para o monitoramento remoto de grupos geradores em operações críticas". 

O banco foi configurado de forma a salvar apenas dados que são diferentes em relação ao dado anterior de forma que os espaços vazios tem o mesmo valor do ultimo dado registrado. alguns parâmetros podem ter valores aparentemente iquais devido ao flutuação de precisão.  

Este trabalho foi desenvolvido no LANCE (Leading Advanced Technologies Center of Excellence). O presente trabalho foi realizado com apoio da Coordenação de Aperfeiçoamento de Pessoal de
Nível Superior - Brasil (CAPES) - Código de Financiamento 001.
