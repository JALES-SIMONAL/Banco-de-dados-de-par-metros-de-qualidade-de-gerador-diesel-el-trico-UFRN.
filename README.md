# Banco-de-dados-de-par-metros-de-qualidade-de-gerador-diesel-el-trico-UFRN.
O presente repositório contém o banco de dados de 29 parâmetros de qualidade de um gerador diesel-elétrico da UFRN como parte das contribuições do artigo "Desenvolvimento de hardware e dashboard supervisório para o monitoramento remoto de grupos geradores em operações críticas".
